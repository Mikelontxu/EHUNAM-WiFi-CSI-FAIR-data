Síntesis

This ontology provides a structured representation of WiFi Channel State Information (CSI) measurements, including details about the measurement environment, involved persons, activities performed, and technical parameters.

Introducción volver a índice

Esta ontología ha sido desarrollada para dar soporte a **EHUNAM**, un conjunto de datos CSI WiFi diseñado para la investigación en detección de actividad humana y de maquinaria. El conjunto de datos EHUNAM fue recopilado a lo largo de múltiples campañas de medición, en varios días y entornos, incluyendo escenarios de interior y un entorno industrial, con la participación de múltiples personas, actividades y máquinas. Los datos se obtuvieron utilizando diferentes configuraciones de hardware (Broadcom y Atheros), herramientas de extracción (Nexmon CSI Extraction y Atheros CSI Tool), y distintos métodos de transmisión, dando lugar a un conjunto de mediciones rico y heterogéneo. Dada esta complejidad, organizar y describir el conjunto de datos de manera consistente resulta esencial para hacerlo verdaderamente accesible y reutilizable por parte de la comunidad investigadora. Esta ontología responde a esa necesidad proporcionando un vocabulario estructurado para representar los elementos clave de cada medición. Al modelar estos elementos de forma formal, la ontología tiene como objetivo facilitar la exploración, consulta e integración del conjunto de datos EHUNAM en futuros estudios, apoyando la reproducibilidad y facilitando la investigación dentro de la comunidad científica.
