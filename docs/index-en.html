Abstract

This ontology provides a structured representation of WiFi Channel State Information (CSI) measurements, including details about the measurement environment, involved persons, activities performed, and technical parameters.

Introduction back to ToC

This ontology has been developed to support **EHUNAM** WiFi CSI dataset designed for human and machine sensing research. EHUNAM dataset was collected over multiple measurement campaigns across several days and environments, including indoor scenarios and an industrial setting, involving multiple participants, activities, and machines. Data was gathered using different hardware configurations (Broadcom and Atheros), extraction tools (Nexmon CSI Extraction and Atheros CSI Tool), and transmission methods, resulting in a rich and heterogeneous body of measurements. Given this complexity, organizing and describing the dataset in a consistent way is essential to make it truly accessible and reusable by the research community. This ontology addresses that need by providing a structured vocabulary to represent the key elements of each measurement. By modeling these elements formally, the ontology aims to make the EHUNAM dataset easier to explore, query, and integrate into future studies, supporting reproducibility and facilitating research in the scientific community.
